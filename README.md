# TILO — время для себя

Интерактивная демоверсия сайта студии красоты на русском языке. Вымышленные услуги, мастера и цены; изображение интерьера создано ИИ. **Не предназначено для работы с реальными клиентскими данными.**

## Локальный запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте `index.html` в современном браузере. Все файлы должны оставаться рядом. Интернет, сборка и установка пакетов для сайта не нужны.

Рекомендуемый вариант со стабильным хранилищем (нужен Python 3):

```bash
git clone https://github.com/shomkee/tilo-site.git
cd tilo-site
python -m http.server 8000 --bind 127.0.0.1
```

Если команда `python` не найдена, попробуйте `python3` (macOS/Linux) или `py` (Windows). Откройте http://localhost:8000. Для остановки нажмите Ctrl+C.

## Проверка

Нажмите «Выбрать время», выберите услугу, мастера, дату и свободный слот. Используйте тестовый телефон **+7 000 000-00-01**, вымышленное имя и код **1234**. СМС не отправляется.

Демо-админка — внизу сайта. Для проверки отзывов и бонусов сначала войдите в кабинет, затем в журнале админки нажмите «Добавить тестовый завершённый визит себе».

## Возможности

- Адаптивная главная, 10 услуг, 4 мастера, категории, акции, отзывы и журнал ухода.
- Запись с учётом графиков, перерывов, длительности и пересечений. Время Europe/Moscow, цены в рублях, горизонт 30 дней.
- Выбор конкретного или любого свободного мастера, удержание времени на 5 минут в одном браузере.
- Демо-вход по телефону, личный кабинет, перенос, отмена, повторная запись, экспорт .ics.
- Промокод ПРИВЕТ (15% на первый визит), начисление 5% бонусов после завершения.
- Отзывы после завершённого визита с оценкой и необязательным тестовым фото.
- Имитация уведомлений, заказов сертификатов и абонементов.
- Демо-админка: журнал, цены/длительность услуг, мастера/графики, клиентские пожелания, загрузка и выручка по завершённым визитам.

## Файлы и данные

- `index.html` — структура сайта.
- `style.css` — оформление и адаптивность.
- `app.js` — логика сайта и демо-данные.
- `hero.svg` — контейнер с оптимизированным WebP-изображением исходного ИИ-интерьера, без внешних запросов.
- `test.cjs` — браузерные тесты.

Стек: HTML, CSS, JavaScript без фреймворков. Структурированная имитация БД в localStorage (`tilo-demo-v1`); текущий профиль — sessionStorage.

Коллекции: users, services, masters, appointments, reviews, holds, notifications, giftOrders. Расписания встроены в masters (рабочие дни, часы и перерыв). Запись фиксирует название, цену и длительность услуги на момент подтверждения.

Слоты перебираются с шагом 15 минут. Интервал должен помещаться в смену и не пересекать перерыв, запись или чужое активное удержание: `newStart < oldEnd && newEnd > oldStart`. При переносе исходная запись исключается из проверки и меняется только после подтверждения.

## Ограничения и безопасность

**Это локальный прототип, а не готовая система онлайн-записи.**

- Нет защищённого входа, ролей, серверной БД и синхронизации устройств. Демо-админка доступна всем в этом браузере.
- Не вводите настоящие персональные, медицинские или платёжные данные.
- localStorage не транзакционный: удержания между вкладками не заменяют серверную защиту от одновременных записей.
- СМС/email, платежи, чаевые и фоновые напоминания не подключены; сертификаты не действительны, бонусы не списываются.
- Контакты, карта, реальные фото мастеров, портфолио и подтверждённые рейтинги требуют подготовки.
- Тексты конфиденциальности и условий описывают только демо и не подтверждают соответствие 152-ФЗ.
- Нет добавления/удаления мастеров и услуг через админку и исключений графика по отдельным датам.

GitHub Pages не включён. Размещение исходников в публичном репозитории не означает публикацию работающего сайта.

## Перед реальным запуском

1. Заменить демо-бренд, прайс, контакты и фотографии.
2. Подключить серверную БД, безопасную аутентификацию, роли и транзакционное резервирование.
3. Настроить СМС/email и очередь напоминаний.
4. Подключить платежи, сертификаты, возвраты и чаевые.
5. Подготовить юридические документы, проверить доступность и согласовать публикацию.
